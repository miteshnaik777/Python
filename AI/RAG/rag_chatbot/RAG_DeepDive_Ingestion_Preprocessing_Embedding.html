Big picture: data flow

The orchestrator is RAGPipeline.ingest() in 06_pipeline/rag_pipeline.py. It loops over (filename, file_bytes) tuples, accumulates chunks from every file, then embeds once and builds one FAISS index per session_id.

flowchart TB subgraph ingest["Per file (loop)"] V["validate_file"] E["extract_text"] C["clean_pages"] K["chunk_pages"] end V --> E --> C --> K K --> A["extend all_chunks"] A --> M["embed_chunks"] M --> B["VectorStore.build"] B --> S["save local disk"]

Optional cloud persistence exists in the codebase but is not required for the local pipeline: indexes are always written under rag_chatbot/tmp/index/.

A. Orchestration: RAGPipeline.ingest

Class: RAGPipeline (06_pipeline/rag_pipeline.py). Method: ingest(files, session_id) returns a dict with session_id, files_processed, total_chunks, and skipped_files.

  • Per-file exceptions: ValidationError (from file validator), ValueError (e.g. unsupported type in extractor), RuntimeError (e.g. optional upload failure). Failed files are logged and listed in skipped_files; others continue.
  • Embedder reuse: self._embedder is loaded lazily via get_embedder() and reused for all chunks in the batch.
  • Vector store: VectorStore(session_id=session_id) receives the full chunk list and embedding matrix, then build() and save().

Core ingest loop (conceptual)

for filename, content in files:
    validate_file(filename, content)
    pages = extract_text(file_bytes=content, filename=filename)
    pages = clean_pages(pages)
    chunks = chunk_pages(pages)
    all_chunks.extend(chunks)
# then: embed_chunks(all_chunks) → VectorStore.build → save

Tip: Read config.cfg (config.py) for limits and model names used by chunking and embedding—single source of truth.

B. Ingestion: file_validator.py

Validation runs before any parsing. It ensures only allowed extensions, non-empty content, and size within limits—acting as a gate before extract_text.

B.1 API surface

  • ValidationError — exception subclass raised when any check fails.
  • validate_file(filename, content) — runs three private checks; returns None on success.
  • _check_extension(filename) — suffix must be in cfg.ALLOWED_EXTENSIONS.
  • _check_not_empty(filename, content) — rejects zero-byte files.
  • _check_size(filename, content) — enforces cfg.MAX_FILE_SIZE_MB.
  • get_file_info(filename, content) — returns a metadata dict (filename, extension, size) after you know the file is valid.
Check Config key (config.cfg)
Extension whitelistALLOWED_EXTENSIONS
Maximum file sizeMAX_FILE_SIZE_MB

B.2 Implementation excerpt

def validate_file(filename: str, content: bytes) -> None:
    _check_extension(filename)
    _check_not_empty(filename, content)
    _check_size(filename, content)


def _check_extension(filename: str) -> None:
    ext = Path(filename).suffix.lower()
    if ext not in cfg.ALLOWED_EXTENSIONS:
        raise ValidationError(
            f"Unsupported file type '{ext}'. "
            f"Allowed: {', '.join(cfg.ALLOWED_EXTENSIONS)}"
        )

C. Preprocessing

C.1 Text extraction — 02_preprocessing/text_extractor.py

extract_text(file_bytes, filename) branches on extension and returns a list of dicts, each with at least text, page, source (filename). This normalized shape feeds the cleaner and chunker.

  • _extract_pdf — PyPDF2 PdfReader; one dict per page with text (pages with no text are skipped).
  • _extract_docx — python-docx; paragraphs grouped into sections; headings bump a section index used as page.
  • _extract_txt — tries encodings utf-8, latin-1, cp1252; fallback utf-8 with errors="replace".
def extract_text(file_bytes: bytes, filename: str) -> List[Dict]:
    ext = Path(filename).suffix.lower()
    if ext == ".pdf":
        return _extract_pdf(file_bytes, filename)
    elif ext == ".docx":
        return _extract_docx(file_bytes, filename)
    elif ext == ".txt":
        return _extract_txt(file_bytes, filename)
    else:
        raise ValueError(f"Unsupported file type: '{ext}'")

C.2 Cleaning — 02_preprocessing/cleaner.py

clean_text(text) normalizes one string: strips control chars (except tab/newline), Unicode NFC normalization, newline harmonization, collapses excessive whitespace, trims lines. clean_pages(pages) applies clean_text to each page dict's text and drops entries that become empty. 

def clean_pages(pages: List[Dict]) -> List[Dict]:
    cleaned = []
    for page in pages:
        text = clean_text(page.get("text", ""))
        if text:
            cleaned.append({**page, "text": text})
    return cleaned

C.3 Chunking — 02_preprocessing/chunker.py

chunk_pages(pages) uses LangChain's RecursiveCharacterTextSplitter (langchain_text_splitters, fallback langchain.text_splitter). It splits on separators in order: ["\n\n", "\n", ". ", " ", ""], preferring large natural breaks first. Chunk length uses character count via len.

Parameters from config

chunk_size = cfg.CHUNK_SIZE (default 500), chunk_overlap = cfg.CHUNK_OVERLAP (default 50). Overlap reduces boundary cuts mid-thought.

Output chunk dicts include text, source, page, and a running chunk_index across the whole ingest batch. chunk_text(text, source) wraps a single string as one synthetic page for convenience. 

splitter = RecursiveCharacterTextSplitter(
    chunk_size=cfg.CHUNK_SIZE,
    chunk_overlap=cfg.CHUNK_OVERLAP,
    length_function=len,
    separators=["\n\n", "\n", ". ", " ", ""],
)

D. Embedding & vector index

D.1 Embedder — 03_embedding/embedder.py

  • get_embedder() — @lru_cache(maxsize=1) loads SentenceTransformer(cfg.EMBEDDING_MODEL, default all-MiniLM-L6-v2) once; dimension cfg.EMBEDDING_DIM (384).
  • embed_chunks(chunks, model=None) — collects chunk["text"], batch-encodes with batch size 32, returns float32 array shape (N, EMBEDDING_DIM).
  • embed_query(query, model=None) — single query string to shape (1, EMBEDDING_DIM); used later by retrieval (outside this doc).

Why normalize_embeddings=True

With L2-normalized vectors, inner product equals cosine similarity. The FAISS index uses inner product (IndexFlatIP), so scores align with cosine without a separate cosine metric.

embeddings = model.encode(
    texts,
    batch_size=32,
    show_progress_bar=False,
    convert_to_numpy=True,
    normalize_embeddings=True,
)

D.2 VectorStore — 03_embedding/vector_store.py

Class: VectorStore(session_id). Constructor creates cfg.LOCAL_INDEX_DIR / session_id for local files.

  • build(chunks, embeddings) — asserts len(chunks) == len(embeddings); builds faiss.IndexFlatIP(dim), add(embeddings), stores parallel metadata list (chunk dicts).
  • _faiss_safe_path(path) — normalizes path strings for FAISS C++ I/O on Windows (avoids invalid-argument errors with some path formats).
  • _save_local() — writes faiss.index via faiss.write_index and metadata.json as UTF-8 JSON.
  • _load_local() — reads both files back; returns False if missing.
  • save() — writes faiss.index and metadata.json under the session directory.
  • load() — restores the index from those local files via _load_local().

D.3 Search (preview)

search(query_vector, top_k) runs index.search(query_vector, k), maps row indices to metadata entries, and adds a score field per hit. Default k comes from cfg.TOP_K. The full retrieval layer (Retriever + query embedding) builds on this; see 04_retrieval/retriever.py when you extend this series. 

self.index = faiss.IndexFlatIP(dim)
self.index.add(embeddings)
self.metadata = list(chunks)

First-run cost

The first call to get_embedder() downloads all-MiniLM-L6-v2 (~90 MB) into your Hugging Face cache. Subsequent runs reuse it.
